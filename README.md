# 灵译 隐私政策

**更新日期：2026-09-24**

灵译（以下简称"本应用"）是一款完全在设备本地运行的拍照英译中工具。我们对你隐私的承诺非常简单：

## 1. 我们不收集任何数据

- 本应用**不收集、不存储、不共享**任何个人身份信息；
- 你拍摄的照片、识别出的文字、翻译结果，**只存在于你的手机内存中**，关闭应用即销毁，不会发送到任何服务器；
- 本应用不含广告、不含分析统计 SDK、不含崩溃上报 SDK、不含任何账号系统。

## 2. 所有处理都在你的手机上完成

- 文字识别由内置的设备端识别模型完成；
- 翻译由系统内置的设备端大模型（Gemini Nano，经 Android AICore 提供）在本地完成；
- 翻译结果生成后仅显示在你的屏幕上，除非你主动使用系统"复制"功能，否则不会离开设备。

## 3. 网络的使用

- 本应用自身不发送你的任何内容到网络；
- 首次使用时，Android 系统组件可能联网下载设备端 AI 模型文件（由 Google 的系统基础设施管理），此后识别与翻译完全离线可用；
- Google 可能按其自身政策接收匿名诊断信息，详见 [ML Kit 条款](https://developers.google.com/ml-kit/terms)。

## 4. 权限说明

| 权限 | 用途 |
| --- | --- |
| 相机 | 拍摄需要翻译的文字（核心功能） |

本应用不请求存储、位置、麦克风、通讯录等其他任何权限。

## 5. 儿童隐私

本应用不面向儿童定向设计，同时因不收集任何数据，也不存在儿童数据问题。

## 6. 政策更新

如本政策发生实质变更，我们会在应用内或本页面说明并更新日期。
